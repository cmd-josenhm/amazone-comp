# Accord de contribution (CLA simplifié)

> Texte provisoire à faire relire par un juriste avant ouverture aux contributeurs externes.

En soumettant une contribution (code, documentation, traduction, données) au projet AMAZONE COMP, vous déclarez que :

1. vous êtes l'auteur de la contribution, ou vous avez le droit de la soumettre ;
2. la contribution est distribuée sous licence **GNU AGPL-3.0** ;
3. vous accordez en plus au propriétaire du projet (**A COMPLETER**) une licence mondiale, perpétuelle, gratuite et irrévocable lui permettant d'utiliser, modifier et redistribuer votre contribution **sous toute autre licence**, y compris commerciale ;
4. votre contribution ne contient aucun secret, aucune donnée personnelle de tiers et aucun code soumis à une licence incompatible.

Pour accepter : cocher la case correspondante dans le modèle de Pull Request.
