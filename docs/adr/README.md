# Registre des décisions d'architecture (ADR)

Format : `NNNN-titre-court.md`, sections Contexte / Décision / Conséquences, statut `Proposé` → `Accepté` (par le chef de projet) ou `Rejeté` / `Remplacé par NNNN`.
Un agent peut **proposer** un ADR (nouveau fichier, statut « Proposé ») ; il ne modifie jamais un ADR existant.
