# Code de conduite

Ce projet adopte l'esprit du [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

- Respect de toutes et tous, sans discrimination.
- Critiques sur le code, jamais sur les personnes.
- Pas de harcèlement, d'insulte ni de contenu offensant.
- Les décisions du chef de projet sont motivées ; on peut les contester poliment par une issue.

Signalement : **A COMPLETER** (contact du propriétaire). Les signalements sont traités de façon confidentielle.
Sanctions possibles : avertissement, exclusion temporaire ou définitive du projet.
